    Python function index#

    For a first reading, use functions in execution order. This generated index contains 479 functions and methods, including private and nested helpers, from the Python package and the two main workflow tools. Sections follow workflow purpose; modules and names are alphabetical within them. Links open the exact definition. The Python API renders full docstrings. Legacy and experimental functions remain listed; their presence here does not make them part of the default runner.

    Regenerate with python tools/render_function_index.py --write. CI checks the index against the source.
