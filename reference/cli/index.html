    Command-line reference#

    Every command of the fasta-lake executable, generated from the code. The runner for a whole study, tools/run_manifest.py, has its own page.

    fasta-lake#

    FASTA Lake: Sample-specific protein database construction for metaproteomics.

    Usage:

    fasta-lake [OPTIONS] COMMAND [ARGS]...

    Options:

      --version  Show the version and exit.
  --help     Show this message and exit.

    Subcommands

    • analyze-study: Export AnnData and run AlphaPeptTools QC, log2 PCA and optional replicate CV.
    • annotate: Annotate selected proteins and inspect explicit annotation gaps.
    • contaminants: Inspect or apply the contaminant database (v5.1).
    • convert: Convert raw mass spec data to de novo predictions.
    • diagnose: Produce FDR calibration curve + outlier sample list.
    • entrapment: Generate, inject and measure entrapment sequences.
    • evidence-lake: Stage 1: Create evidence lake from peptide predictions.
    • explore-study: EXPERIMENTAL: inspect annotated signal, coverage, diversity and CLR PCA.
    • export: Prepare a FASTA for a specific search engine.
    • extract-chunked: Build evidence in bounded reference pieces and merge before inference.
    • extract-sample: Stage 2: Extract per-sample protein database.
    • infer: Experimental Python inference, distinct from the validated Rust workflow.
    • init: Generate an example fastalake.json configuration.
    • lake-build: Stage 0: Build reference protein lake from databases.
    • lake-inspect: Query a lake provenance sidecar produced by lake-merge.
    • lake-merge: Merge multiple source FASTAs into one lake with field-level annotation merge (v5.2).
    • molecular: Prepare TPM inputs, select exact proteins and compare matched searches.
    • network: Export peptide memberships and render experimental CKG network views.
    • plan-resources: Show laptop planning choices without starting a workflow.
    • preset: Inspect or export validated parameter presets (v5).
    • quantify-study: Quantify completed study groups and retain peptide/ion support diagnostics.
    • resources: Choose, size and download public reference databases and model weights.
    • taxonomy: Export Unipept queries and plot its saved taxonomic assignments locally.
    • tune: Recommend SAGE parameters by post-hoc sweep over existing entrapment results.
    • validate: Validate a FASTA Lake JSON configuration file.

    fasta-lake contaminants#

    Inspect or apply the contaminant database (v5.1).

    FastaLake bundles a minimal contaminant accession list (keratins, trypsin, BSA, caseins, IgGs, etc.). Proteins matching this list are tagged with a CON_ prefix; downstream FDR accounting can exclude them via fasta_lake.contaminants.exclude_contaminants().

    Usage:

    fasta-lake contaminants [OPTIONS] COMMAND [ARGS]...

    Options:

      --help  Show this message and exit.

    Subcommands

    • list: List the bundled contaminant accessions.
    • tag: Scan a FASTA, prefix CON_ on headers matching the contaminant list.

    Options:

      --help  Show this message and exit.

    fasta-lake convert#

    Convert raw mass spec data to de novo predictions.

    Handles the full chain: .raw → .mzML → .hdf → predictions.csv

    Each step can be run independently or all at once:

    raw-to-mzml Thermo .raw → .mzML (ThermoRawFileParser v2) mzml-to-hdf .mzML → .hdf spectral library (AlphaNovo converter) hdf-to-csv .hdf → predictions.csv (AlphaNovo inference) all Run all steps in sequence

    IMPORTANT: AlphaNovo inference uses save_speclib=false to prevent HDF corruption. The --validate flag (on by default) checks that input HDFs are clean before running inference.

    Examples:

    # Full pipeline from raw files fasta-lake convert -i data/raw/ -o data/predictions/ --step all

    # Just convert mzML to HDF fasta-lake convert -i data/mzml/ -o data/hdf/ --step mzml-to-hdf

    # Run inference on clean HDFs fasta-lake convert -i data/hdf/ -o data/pred/ --step hdf-to-csv --checkpoint rope

    Usage:

    fasta-lake convert [OPTIONS]

    Options:

      -i, --input PATH                Input: .raw file, .mzML file, .hdf file, or
                                  directory of any  [required]
  -o, --output PATH               Output directory for converted files
                                  [required]
  --step [raw-to-mzml|mzml-to-hdf|hdf-to-csv|all]
                                  Which conversion step(s) to run (default:
                                  all)
  --checkpoint [old|rope]         AlphaNovo checkpoint for de novo inference
                                  (default: rope)
  --validate / --no-validate      Validate HDF files before inference (catches
                                  corruption)
  -v, --verbose
  --help                          Show this message and exit.

    fasta-lake diagnose#

    Produce FDR calibration curve + outlier sample list.

    For each entrapment type (shuffled, plant, archaea), computes empirical combined-method FDP at a grid of nominal q-value thresholds. Writes calibration_curve.csv. Also flags samples with outlier FDP for review.

    Usage:

    fasta-lake diagnose [OPTIONS]

    Options:

      --results-dir PATH     Directory with per-sample entrapment results (same
                         layout as `tune`).  [required]
  -o, --output-dir PATH  Output directory for calibration curve + outlier
                         list.  [required]
  --min-length INTEGER   Peptide min length (applied post-hoc). Default 9.
  --z-threshold FLOAT    Z-score threshold for outlier flag. Default 2.0.
  -v, --verbose
  --help                 Show this message and exit.

    fasta-lake entrapment#

    Generate, inject and measure entrapment sequences.

    Entrapment gives an FDR estimate independent of target-decoy: sequences known to be absent from the sample are put into the database, and anything that matches them is a false discovery.

    WHERE entrapment is injected decides WHAT is being measured. Four points exist, earliest (hardest to survive) first: prelake into the input lake BEFORE the cohort evidence filter. Faces every curation step: the fullest construction test. prebuild onto the clustered lake, then RE-CLUSTERED at 97%, so entrapment must also survive clustering. preselect onto the clustered lake, no re-clustering (DEFAULT). Must be nominated by the sample's own de novo peptides. appended onto the finished per-sample database AFTER parsimony, entering untested. Measures SEARCH error, not construction.

    prebuild and preselect are NOT the same stage under two names. All are legitimate, none are the same quantity, so these commands record the stage in every output and refuse to pool across stages or classes.

    PREFIXES are not uniform in this repo: ENTRAP_PFUR_/ENTRAP_SHUF_/..., but also ENTRAPHUMAN_ (SIHUMIx) and ENTRAPNN_ (near-neighbour), which do NOT match ENTRAP_. A wrong pattern scores entrapment as target and drives the FDP to zero silently. The default pattern is the common denominator ENTRAP; check any lake with fasta-lake entrapment prefixes <fasta>.

    Typical run: fasta-lake entrapment classes fasta-lake entrapment generate --class shuffled --source lake.fasta \ -o entrap.fasta fasta-lake entrapment inject -d lake.fasta -e entrap.fasta \ -o augmented.fasta --class shuffled # ... run the pipeline on augmented.fasta, then search ... fasta-lake entrapment fdp --results-dir results/ --target-fasta lake.fasta \ -o fdp/

    Usage:

    fasta-lake entrapment [OPTIONS] COMMAND [ARGS]...

    Options:

      --help  Show this message and exit.

    Subcommands

    • classes: List entrapment classes with their difficulty and interpretation.
    • fdp: Compute the FDP from search results, with n, median, IQR and bootstrap CI.
    • generate: Produce an entrapment FASTA, deterministically.
    • inject: Concatenate entrapment into a database and write a manifest.
    • prefixes: Report the entrapment prefixes actually present in a FASTA.
    • prepare: Generate + inject entrapment as configured by a fastalake.json.

    fasta-lake entrapment classes#

    List entrapment classes with their difficulty and interpretation.

    The classes do NOT measure the same thing. Read the caveats before comparing any two numbers produced with different classes.

    Usage:

    fasta-lake entrapment classes [OPTIONS]

    Options:

      --json  Emit the full registry as JSON.
  --help  Show this message and exit.

    fasta-lake entrapment fdp#

    Compute the FDP from search results, with n, median, IQR and bootstrap CI.

    Reports raw and conserved-corrected FDP together, and states how many samples were evaluable. A sample with no entrapment sequences in its searched database has an UNDEFINED FDP, not a zero, and is excluded rather than counted as 0.0.

    Usage:

    fasta-lake entrapment fdp [OPTIONS]

    Options:

      --results-dir PATH              Directory of per-sample search results
                                  (SAMPLE/results.sage.tsv or
                                  SAMPLE/*/results.sage.tsv).  [required]
  -o, --output-dir PATH           Output directory for the per-sample TSV and
                                  the FDP record.  [required]
  --dataset TEXT                  Dataset/cohort name for the record.
  --class TEXT                    Entrapment class. Read from the manifest
                                  when present; an explicit value that
                                  contradicts the manifest is refused.
  --stage [prelake|prebuild|preselect|appended]
                                  Injection stage. Read from the manifest when
                                  present. Required if no manifest exists --
                                  it will not be guessed.
  --target-fasta PATH             Target sequence space for the conserved-
                                  peptide test. Every entrapment-attributed
                                  peptide is checked for occurrence here (I/L
                                  normalised, exact substring); those found
                                  are genuinely conserved, not false
                                  discoveries. Required for homologous classes
                                  such as plant.
  --no-conserved-check            Skip the conserved-peptide correction and
                                  report an explicitly UNCORRECTED FDP.
  --normalize-il / --no-normalize-il
                                  Treat I and L as equivalent when matching.
                                  Default: on.
  --q-threshold FLOAT             FDR cutoff. Default 0.01.
  --q-column TEXT                 FDR column. Default peptide_q.
  --min-length INTEGER            Peptide length floor. Default 9.
  --entrap-prefix TEXT            Header prefix identifying entrapment.
                                  Defaults to what the manifest recorded, else
                                  the class prefix. Set this when the run used
                                  a non-standard convention such as
                                  ENTRAPHUMAN_ or ENTRAPNN_ -- a wrong pattern
                                  silently reports ~0% FDP.
  --decoy-prefix TEXT             Decoy tag, used only if the results have no
                                  `label` column. SAGE writes rev_.
  --db-pattern TEXT               Glob (relative to a sample dir) for that
                                  sample's searched FASTA, e.g.
                                  '*_razor.fasta'. Enables per-sample database
                                  partition sizes and the size-corrected
                                  estimators.
  --results-name TEXT             Results filename, or
                                  '<subdir>/results.sage.tsv' to choose one of
                                  several entrapment runs inside a sample
                                  directory.
  --peptide-level                 Count distinct peptides instead of spectra.
  --allow-mixed                   Permit pooling across injection stages or
                                  classes. Produces a number that mixes
                                  different quantities; use only deliberately.
  --entrapment-seed INTEGER       Seed for the bootstrap CI. Default 42.
  --bootstrap-draws INTEGER       Bootstrap draws. Default 2000.
  -v, --verbose
  --help                          Show this message and exit.

    fasta-lake entrapment generate#

    Produce an entrapment FASTA, deterministically.

    Headers are tagged with the class prefix (ENTRAP_SHUF_, ENTRAP_PFUR_, ...) so downstream hits can be attributed. The same seed and input always produce a byte-identical file.

    Usage:

    fasta-lake entrapment generate [OPTIONS]

    Options:

      --class TEXT                    Entrapment class (default: shuffled, the
                                  recommended headline class). See `fasta-lake
                                  entrapment classes`.
  -i, --source PATH               Source FASTA. Required for --class shuffled
                                  (the sequences to shuffle -- normally the
                                  lake you will inject into) and for classes
                                  with no bundled default. Overrides the class
                                  default.
  -o, --output PATH               Output entrapment FASTA.  [required]
  --entrapment-seed INTEGER       Random seed; same seed gives a byte-
                                  identical file. Default 42. Zero is
                                  rejected.
  -n, --n-proteins INTEGER        Write only N proteins, chosen by seeded
                                  subsample. Default: all.
  --prefix TEXT                   Override the class header prefix (default:
                                  the class's own).
  --preserve-cleavage-sites / --no-preserve-cleavage-sites
                                  Hold K/R in place when shuffling so tryptic
                                  peptide lengths match the source. Default:
                                  on.
  -v, --verbose
  --help                          Show this message and exit.

    fasta-lake entrapment inject#

    Concatenate entrapment into a database and write a manifest.

    The manifest records the stage, the class, the seed, the entrapment:target ratio and the counts. Protein counts come from header lines only.

    Usage:

    fasta-lake entrapment inject [OPTIONS]

    Options:

      -d, --database PATH             Database to inject into. For the pre-
                                  selection stages this is the lake that de
                                  novo selection will run against; for
                                  appended it is the finished per-sample
                                  parsimony FASTA.  [required]
  -e, --entrapment PATH           Entrapment FASTA from `entrapment generate`.
                                  [required]
  -o, --output PATH               Augmented FASTA to write.  [required]
  --stage [prelake|prebuild|preselect|appended]
                                  Injection stage, earliest first: prelake
                                  (before the evidence filter), prebuild (re-
                                  clustered with the lake), preselect
                                  (default; clustered lake, no re-clustering),
                                  appended (after parsimony). The first three
                                  measure database-construction error and
                                  differ by how much curation entrapment
                                  survived; appended measures search error.
                                  Recorded in the manifest so the result
                                  cannot be misread later.
  --class TEXT                    Entrapment class, recorded in the manifest
                                  along with its difficulty and
                                  interpretation.
  --entrapment-seed INTEGER       Seed used to generate the entrapment, for
                                  the manifest.
  --entrap-prefix TEXT            Header prefix identifying entrapment.
                                  Defaults to the class prefix, or ENTRAP when
                                  no class is given. Recorded in the manifest
                                  and reused by `entrapment fdp`.
  --manifest PATH                 Manifest path (default:
                                  entrapment_manifest.json beside output).
  --no-checksums                  Skip SHA-256 of the inputs.
  -v, --verbose
  --help                          Show this message and exit.

  -v, --verbose
  --help                          Show this message and exit.

    fasta-lake extract-sample#

    Stage 2: Extract per-sample protein database.

    With -c/--config and entrapment.enabled: true, entrapment is injected into the database before extraction (stage pre-selection), which is what makes an entrapment hit a measurement of database-construction error rather than of search error.

    Usage:

    fasta-lake extract-sample [OPTIONS]

    Options:

      -d, --database PATH             [required]
  -p, --predictions PATH          [required]
  -o, --output PATH               [required]
  -s, --source-tag TEXT
  --normalize-il / --no-normalize-il
  --output-hits PATH
  -t, --threads INTEGER
  -c, --config PATH               FastaLake JSON config. When
                                  `entrapment.enabled` is true and the stage
                                  is pre-selection, entrapment is generated
                                  and injected into --database first, so

    fasta-lake tune#

    Recommend SAGE parameters by post-hoc sweep over existing entrapment results.

    Takes a directory of SAGE entrapment searches, applies a grid of (q_threshold, min_length, min_score) filters, and recommends the filter combination that achieves --target-fdp while maximising target PSMs.

    Runs in seconds on 100s of samples — no re-search required.

    Usage:

    fasta-lake tune [OPTIONS]

    Options:

      --results-dir PATH        Directory with per-sample entrapment results. Each
                            sample subdir must contain entrapment/,
                            entrapment_plant/, and/or entrapment_archaea/
                            subdirs with results.sage.tsv inside.  [required]
  -o, --output-dir PATH     Output directory for tuning_report.csv and
                            recommended.json.  [required]
  --target-fdp FLOAT        Max acceptable shuffled FDP (percent). Default
                            2.0.
  --target-db-size INTEGER  Target database size used for r = E/T. Default
                            75000 (typical MP sample).
  -v, --verbose
  --help                    Show this message and exit.
