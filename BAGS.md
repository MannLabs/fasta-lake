# AlphaNovo bags and mass alternatives in FastaLake

Experimental branch, 23 September 2026. The existing manuscript and exact-lookup
default are unchanged. Read this before interpreting the new Slurm study.

## What is being tested

The primary experiment uses the supplied AlphaNovo paper's reference-explanation
method, with its metaproteome chemistry setting: exact I/L-normalized lookup,
recorded order bags, and up to two composed mass substitutions. The substitutions
are generated by AlphaNovo's actual `build_swap_table`, `generate_variants` and
`generate_modified_mass_equivalent_variants`, pinned to MannLabs/alphanovo
`93d647cf1d996864c3367d5f04e880b5df08d977` (`feat/entrapment-workflow`).
D-to-N and E-to-Q deamidation reversions are disabled, as in the paper's
metaproteome candidate screen. No broader modification search is silently added.

The six comparisons are exact, exact + order bags, exact + mass alternatives,
exact + both, and two independently scrambled-query combined controls. Mass
substitutions include order swaps, so the two relaxed routes can overlap.

Archived AlphaNovo rank-zero results provide the predictions, scores, recorded
bags and modified spellings. The original positive-score, complexity, length
9–50 and per-acquisition top-30%-with-ties filters define lookup eligibility.
Predictions below that threshold retain their existing exact parsimony support;
they do not receive new ambiguity expansion in this experiment. Each original
I/L-normalized prediction sequence is one selection-evidence unit. Its multiple
spellings, spectrum occurrences and compatible proteins do not create additional
independent evidence. This prevents duplicate votes, but does not remove the extra
chances for an unrelated protein to match one of the alternatives. All original
row and spectrum IDs remain recorded.

The all-hit Rust scan searches each complete reservoir and retains every protein
supported by an eligible query. Whole-protein streaming is equivalent to pooling
the same lookup queries before acquisition-specific selection, without restricting
the experiment to the old exact-selected study space. It does not discard contexts
already present in the baseline. Fixed unique/total original-query counts and
FNV-1a accession tie-breaking select whole proteins anew for each comparison.
The exact arm must reproduce the archived selected accessions and sequences before
the downstream jobs are released. Alternative arms may gain or lose proteins.

Sage 0.14.6 uses each acquisition's frozen search configuration and original mzML.
Search acceptance, gained/lost identities and spectra are retained separately.
The four authentic comparisons then produce independent cohort-level reporting
dictionaries and sum quantities using the current FastaLake code. These grouping
labels need not correspond between independently selected search spaces.
Optional AlphaPeptTools PCA and later biological/functional reanalysis remain
separate endpoints; this run does not automatically replace manuscript biology.

## What the paper and upstream code actually say

The supplied `_Nature_Biotech__AlphaNovo (1).docx`, Methods 4.2.1–4.2.3, distinguishes
fragment-resolved anchors, unresolved order bags, and isobaric substitutions.
For example `PE[PT](I/L)DE` represents the PT/TP and I/L alternatives. Order bags
preserve length and composition; mass substitutions can change composition and
length (`N↔GG`, `Q↔AG/GA`, `AD↔GE`). AlphaNovo uses a local absolute 0.02-Da
tolerance per substitution; this is not a new precursor-ppm acceptance rule.
The native two-round generator is used, including its possibility of edits to
already modified intermediate strings. CAM-C alternatives are generated separately,
not multiplied with every other substitution.

AlphaNovo's discovery caller **excludes** predictions explainable by references
and appends the remaining peptide sequences. FastaLake instead **retrieves**
compatible full proteins and searches the original spectra. Its entrapment builder
also requires fully resolved predictions; that input filter is deliberately not
copied because it would remove the very unresolved bags being tested here.
The original caller's `find_any` stopping rule, omission of already-exact queries,
and handling of unsearchable bags are not all-protein retrieval semantics.
FastaLake retains exact support for an unsearchable bag and records the skipped
relaxed route. It does not discard the original query.

The newer `feat/mass-bag-matching` branch, pinned separately at
`04ab8a4e6722969bae66ea470d703eda327b4b9c`, is a different method. It uses original
token masses, sums only unresolved intervals and keeps resolved tokens separate.
A resolved N can match GG, but two resolved G tokens cannot merge into N. It also
allows reference-side deamidation, CAM-C, oxidation and phosphorylation, with a
shared two-modification budget inside bags; resolved modifications do not spend
that budget. Its caller excludes high-fanout queries for memory reasons. That
branch is not silently substituted for the supplied paper, and has not been
launched as tonight's primary experiment. Its 59 focused tests passed during review.

Neither upstream reference matcher can simply load a 233–375-million-protein
reservoir as a Python dictionary here. Native AlphaNovo compiles the alternatives;
FastaLake's streaming engine supplies all-hit retrieval. Matching is checked
against native AlphaNovo results on fixtures, including boundaries, modifications,
wrong order and I/L. A pattern-count guard fails the run rather than truncating it.

## Scope, controls and speed

The archived roster has 710 acquisitions: 15 CAMPI, 58 healthy stool, 306 PREDICT,
and 331 CapScan. The clinical reservoirs are assembly-inclusive. This is not yet a
repeat of the paper's separate public-only FL-versus-MG benchmark. Those matched
296/282-acquisition comparisons require their own reservoir-specific runs.

The same spectra are used first to select proteins and then to search the selected
proteins with Sage. Search decoys may not reproduce that selection step. This
concern applies to exact matching and may increase with relaxed matching.
More identifications at the same Sage q-value establish a difference in nominally
accepted yield; they do not establish better sensitivity at the same actual FDR.
**The false discovery rate of the full workflow remains unverified.** A successful
pilot gate checks execution and accounting only, and cannot close this endpoint.

[The separate entrapment diagnostic](BAGS_ENTRAPMENT.md) includes proteins from
independently confirmed absent species before retrieval and selection, carries
selected controls through Sage, and compares exact, bag, mass and combined arms.
It requires an attributable absence record and complete possible-present references
including contaminants. It has not yet supplied biological calibration results.

Scrambled queries test accidental retrieval. They are not absent-species entrapments
and do not calibrate the false-discovery rate of added identifications. The
AlphaNovo entrapment FDP formula applies to its defined additional-plus-entrapment
peptide population, excluding reference identifications; its numerical error rates
cannot be imported into this whole-protein selection experiment. Shared spectrum
reuse for selection and search remains explicit.

Timing records distinguish query compilation, the joint reservoir scan, selection,
each Sage search and downstream grouping. `/usr/bin/time -v` records memory for
the scan and searches, and Slurm records whole-job resources. All six selection
comparisons share one scan; its time is a joint cost, not six separate timing
measurements. No speedup is claimed before the measurements are available.
Full-cohort jobs depend on four complete acquisition pilots, unchanged exact
baselines and mechanical search checks. Adverse gains/losses cannot fail the gate.

## Code entry points and validation

- `fasta_lake/bags.py`: pinned upstream calls, query provenance, controls and selection.
- `rust/fasta_extractor_v2/src/bin/bag_extract.rs`: complete streaming protein retrieval.
- `tools/run_bags.py`: frozen-manifest candidate, search, gate, group and collection stages.
- `tests/test_bags.py`: native matching parity and original-evidence accounting.

The upstream entrapment/mass/order suites passed 101 tests; the newer mass-bag suite
passed 59. Affected FastaLake checks passed 16 tests; ten directLFQ-dependent
checks were skipped because that optional backend is absent in the AlphaNovo
runtime. Sum quantification is used here. The first Slurm pilots exposed a standalone
N-terminal modification in archived predictions. Terminal tokens are now preserved
at their termini when constructing controls and excluded from residue permutation;
regression checks cover this input and native CAM expansion. The failed attempt
and its automatically cancelled dependent jobs are preserved in the workstream. Passing fixtures does not establish
full-reservoir resource feasibility, identification gains or workflow calibration.

Exact inputs, branch identities, source-paper hash, job IDs, outputs and outstanding
endpoints are recorded in the associated private A04 workstream handoff. No
manuscript, source prediction, reservoir or previous analysis output is overwritten.

## Matched null comparison after Philip's review

The original six-arm run searches each shuffled seed with combined matching.
It does not by itself isolate the extra accidental retrieval caused by bags.
`tools/run_bag_nulls.py` adds exact-only, bag and mass selection/search arms for
both of those same seeds. All routes were already recorded by the full native
scan, so the extension reuses completed candidate records and original-query
provenance; it never rescans a reduced, authentic-selected reservoir.

The comparison retains the full queried denominator, including zero-hit queries,
and reports hit fractions by length, protein multiplicity, selected proteins,
paired gains/losses and nominal Sage yield. Exact-zero denominators produce an
undefined ratio, alongside the absolute counts. Existing combined searches are
reused only for their matching seed. Null-derived FASTAs can contain real proteins;
identifications from them are not automatically false. These comparisons assess
null behavior under relaxed matching but do not replace absent-species validation.
